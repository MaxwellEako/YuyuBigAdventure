# 心阵棋局 · Heart Gambit

在线游玩：https://maxwelleako.github.io/YuyuBigAdventure/ 。推送到 `main` 后由 GitHub Actions 自动测试、构建并发布到 GitHub Pages。

一个 Three.js 回合制战棋 Demo。墨水瓶打翻在棋盘上，黑棋一枚接一枚醒了过来，白兵屿屿要走完一个序章和 **11 个章节**，每一章都是一张 8×8 棋盘。

序章只有一条直走廊和一只墨渍怪，用来教红心矩阵和攻击形状。每个新机制第一次出现时都会弹出一张说明卡，看过的不再弹出；在玩法说明里可以关闭新手提示。

## 启动

开发环境使用 Node.js 24，浏览器需要支持 WebGL 2。

```bash
npm install
npm run dev       # 自动打开 http://localhost:5173
npm run build     # 生成 dist，可部署到任意静态网站服务
npm run preview   # 本地预览生产构建
```

## 给主角起名

第一次进入游戏（以及重置进度之后）会先问“你叫什么名字？”。名字最多占 18 个显示宽度：**中文最多 9 个字，英文最多 18 个字母**，中英混写按宽度折算（中文算 2，英文算 1）。只能使用文字、数字和 `· . _ -`、空格，名字会随存档保存，之后战斗、章节故事、技能与新手说明里都用它称呼玩家；在标题页可以点「更改名字」修改。没有名字时（例如直接跑逻辑层的单元测试）退回默认名「屿屿」。名字的校验与全局读写在 `src/battle/data/heroName.js`，起名界面在 `src/battle/ui/nameEntry.js`。

### 开发者模式

起名时输入管理员名字 `xrephmos_admin`（区分大小写）即进入开发者模式，顶栏和章节选择旁会出现黑底的 DEV 标记：所有章节都能直接选择；开局就拥有全部武器和技能，每件武器拿满它能拿到的全部强化（含进阶强化），武器槽开到 5 个，所有机制直接解锁。开发者模式下通关不写入正式存档（星级、解锁进度、构筑、铁砧记录都不变），改回普通名字后一切照旧。这只是方便测试的开关，网页代码对所有人可见，不是安全措施。

## 界面风格

所有弹窗的高度都不超过屏幕的可见区域，内容多时在弹窗里滚动；手机上的构筑、玩法说明、章节选择、铁砧是整页，由整页滚动。

界面采用瑞士国际主义风格（Swiss Style）：灰白纸底 + 单一强调色克莱因蓝 IKB（#002FA7），Inter / Noto Sans SC 无衬线与 JetBrains Mono 元数据，字号越大字重越细，全部直角、纯色、1px 细线，不用阴影、渐变和圆角。约定：**IKB 实底 = 你的攻击或操作，墨黑实底 = 怪物的攻击**，红色只用于红心本身。3D 棋盘是纸白与浅灰两色棋格配墨黑细线，桌面印着与棋格对齐的极细网格。障碍统一是灰色长方体，一眼能认出此路不通。棋子是程序化车削的设计师棋具：主角屿屿是 IKB 釉面小兵，系白色围巾、佩短剑；怪物是黑色漆面的兵、马、象、车、后、王与一滴墨渍，底座与领口有细白线装饰。

## 教学节奏

战斗机制按章节逐步解锁，还没教的按钮不出现，每章第一场战斗只讲这一章新增的内容（解锁表在 `src/battle/data/features.js`）：

| 章节 | 新增 |
| ---- | ---- |
| 序章 | 只有短剑：双方的红心矩阵、怪物的下一招、攻击 |
| 第 1 章 | 通关序章获得钩镰：连击、充能、追击、红心药水 |
| 第 2 章 | 防御、等待 |
| 第 3 章 | 撤退 |

解锁看的是走到的最远章节，回头重玩序章时已学会的机制照样能用。

## 核心机制：红心矩阵

- 主角和怪物的生命都是一个 **二维红心矩阵**，矩阵被清空即倒下。怪物的矩阵形状各不相同（十字、菱形、带空槽的不规则形），部分怪物有需要命中两次的 **护甲心**。
- 每件武器按 **固定形状** 消除红心，形状 **不能旋转、不能镜像**，也 **不设边界**：越出矩阵的部分直接忽略。例如 钩镰（`@#` / `#.`）对准 4×4 矩阵的 a00，会消除 a00、a01、a10；把锚点放到矩阵外，就可以只擦到边缘的一格。
- 战斗窗口左侧是怪物的心阵，右侧是自己的心阵。红心统一使用 7×6 的像素红心。鼠标 **悬停在怪物心阵上预览形状**（小方块是锚点），点击出招。矩阵始终在框内居中，四周铺满与红心格同样大小的虚线“界外格”，形状可以伸到界外。
- 怪物同样用形状攻击，并按固定的 **招式循环** 出招；下一招的形状和 **瞄准位置** 会提前用墨黑色标在你的心阵上。

| 武器 | 形状 | 冷却 | 获得 |
| ---- | ---- | ---- | ---- |
| 短剑 | 横向 2 格 | 无 | 初始 |
| 钩镰 | L 形 3 格 | 1 | 序章通关 |
| 斜刃 | 斜向 2 格 | 无 | 第 1 章宝箱 |
| 长枪 | 竖直 3 格 | 1 | 第 2 章宝箱 |
| 月镰 | 斜向 3 格 | 1 | 第 3 章宝箱 |
| 战锤 | 2×2，3 点充能 | 1 | 第 4 章宝箱 |
| 破甲锥 | 竖直 2 格，一击击碎护甲心 | 1 | 第 5 章宝箱 |
| 圣十字 | 十字 5 格，3 点充能 | 1 | 第 9 章宝箱 |

长枪与月镰以中间一格为锚点，其余武器以左上角为锚点。武器按「小而灵活、大而笨重」分档：短剑、斜刃两格无冷却，是轮换刷连击的主力，但不能延长、不能破甲；钩镰、长枪、月镰、破甲锥负责接招；战锤、圣十字一下打得多，每次花 3 点充能，比开局持有的 2 点多，必须先打出连击才能抡起来，所以重武器是连击的收尾而不是开场的蛮力；怪物蓄力之后的那一记重击，重武器一下打碎 3 颗心就能把它打断。战锤推迟到第 4 章（中期）才拿到。每章宝箱里的武器都是为接下来几章的怪物准备的：长枪对骑士，战锤对会回血的主教，破甲锥对城堡。怪物的护甲、回血、蓄力重击、打断连击这些特性，在情报卡和敌人列表里用小图标标出。

**武器槽与构筑**：带进战斗的武器数量受武器槽限制。序章到第 2 章有 2 个槽，第 3～5 章 3 个，第 6～8 章 4 个，第 9 章起 5 个。从第 2 章开始，拥有的武器种类始终多于武器槽，多出的放在背包里。武器槽增加时不会从背包自动补上，新学会的技能也只会放进空着的技能槽，不会替换已带的技能。在棋盘上按 `B` 或点武器标题旁的「构筑」，左边是出战的武器槽和技能槽，右边是背包，点卡片就能在两侧之间移动；槽位满了时，先点背包里的卡，再点左边要换下的那张。战斗中不能换。

**武器强化**：从第 2 章起每章都有铁砧，镜厅、王后回廊、王城禁卫和终章各有两座，一共 14 座。站在旁边点击它，从三项强化中选一项。每一项可以单独刷新一次，关闭后再打开，选项保持不变；每座铁砧只能用一次。所有强化都不改变两条核心规则——**每一击必须紧挨上一击**、**每一格都要落在红心上**。强化分两层：

| 定位 | 基础强化（补短板，黑底标记） | 进阶强化（放大长处，稀有，蓝底标记） |
| --- | --- | --- |
| 轻武器（短剑、斜刃）：永远两格的“垫刀” | 精准（用它接上连击时多得 1 点充能）、吸血（用它打出追击时回复 2 颗红心）、招架（用它接上连击时，怪物下一招少打 1 颗心，每回合最多一次；伤害预告里少算的那一格画成蓝框）、变形 | 连锁（连上时连击多涨一次）、死灭（用它接上连击时，消除的格子从心阵上抹去，怪物无法在此回血；被抹去的格子中间画一个黑色的 ×，表示这里曾经有过心） |
| 中型（钩镰、长枪、月镰、破甲锥） | 延长（战斗中可切换为多一格的形状）、破甲、变形 | 贯通（直线形武器：完整落在红心上时，沿自身方向一直延伸到空位为止） |
| 重武器（战锤、圣十字） | 延长（可切换：战锤 2×2 ↔ 2×3，圣十字臂长 1 ↔ 2）、震慑（打碎 2 颗心就能打断重击）、破甲 | 巨化（需先有延长：多一枚巨化按钮，战锤 3×4、圣十字臂长 3；延长、巨化各自开关，可以直接互相切换）、震地（打断重击时怪物再晕眩一回合） |

变形指战斗中按 `R` 旋转、按 `F` 镜像，每项只提供一种，由武器决定：短剑、长枪、破甲锥可旋转，月镰可镜像，钩镰两种都能获得，战锤与圣十字变形后形状不变，所以没有。延长用 `X`、巨化用 `G` 开关，按下切到那一档范围，再按一次回到原形状，同样不占回合。旧存档里的垫步会自动换成招架。进阶强化按整局控制稀有度：从开始到通关一共只有 1～3 座铁砧会给出进阶强化（概率 1/4、1/2、1/4，期望 2 座），开新档时就排好是“第几次使用铁砧”，分散在终章之前的铁砧里，中途退出、重开章节都不会改变；排到的那一座，三项里恰好一项是进阶强化，刷新时进阶只刷成进阶、基础只刷成基础。若那时手上已没有能拿的进阶强化，就顺延到下一次。进阶卡片是黑底蓝框、右上角标“进阶”。破甲在护甲怪出场之后才会刷出，破甲锥自带；震慑、震地在会蓄力重击的骑士出场之后才会刷出；死灭在会回血的主教出场之后才会刷出。招式卡上只画被动效果类的强化（一行两枚、最多三行，进阶强化排在最前），旋转、镜像、延长、巨化选中武器后出现对应按钮。强化会带到之后的章节。

**连击与充能**：攻击形状的每一格都落在还有心的格子上（护甲心也算），就是一次完美命中，它的位置留下蓝色虚线框。换一件武器，挨着虚线框再打一次完美命中，就连成了连击；打空、离虚线框太远或连用同一件武器，连击就断了。连击 ×2 起，每连上一次得 1 点充能（带白色描边的蓝色菱形），每场战斗开局有 2 点，最多积蓄 5 点。短剑、斜刃这些轻武器不花充能；钩镰、长枪、月镰、破甲锥每次花 1 点，战锤、圣十字每次花 3 点，中型、重型武器的冷却都只有 1 回合。

**追击**：连击到 ×3、×6、×9……时触发追击，怪物行动前再出一招。战斗窗口左上角、充能下方有一条三格的追击进度：每连上一下亮一格，亮满时追击图标点亮；悬停在能接上的落点时下一格显示斜纹预告，会断连时整排变成虚线。追击本身（以及疾风斩的追加攻击）不会再触发追击。怪物的心阵是给武器“拼”的：顺着形状换着武器连下去，比一件武器慢慢磨快得多，挨打也少。序章的墨渍怪短剑 → 钩镰 → 短剑三下拼完；暗影兵短剑、钩镰轮换，连击 ×3 时追击收尾。测试里有一个连击求解器，用真正的战斗规则逐一验证：每种怪物在首次登场的章节，用当时拥有的武器（不超过武器槽数）都能一条连击拼完，而且比短剑硬磨回合数少；后期怪，以及手里只有两件武器的第 1 章，只要求连出第一次追击。

**技能**：技能不占武器槽，技能槽固定 3 个，可以在构筑界面更换。每章只能使用有限次数，章节开始时恢复。疾风斩（第 3 章）攻击后可以立刻再用一次普通武器；定身钉（第 5 章）让怪物跳过下一次行动；碎甲（第 6 章）敲碎两格，护甲一击即碎；陨星（第 8 章）攻击 3×3；汲血（第 9 章）消除几颗红心就恢复几颗。

另有 **防御**（不消耗回合，挡下一次伤害，冷却 3）、**红心药水**（消耗回合，在自己心阵上用十字形恢复失去的心；和出招一样点一下预览、再点一次确认；电脑上主角心阵下沿出现提示条，右侧的关闭按钮或 Esc 取消、不消耗药水；手机竖屏上主角心阵从原位置弹出一个放大、略微倾斜的浮窗，右上角白色小方框里的 × 取消；棋盘上也能喝）、**等待**（所有武器都在冷却时跳过这一回合）和 **撤退**（怪物追击一次后晕眩 2 回合，Boss 战不可撤退）。

## 棋盘与怪物

- 与怪物相遇则触发战斗。
- 怪物按棋子规则移动：暗影骑士跳马步追击、暗影主教走斜线并会祷告回血、暗影城堡沿走廊巡逻并给心披甲、暗影王后八方追击，终章的暗王坐镇出口，击败它才能解开封印。
- 怪物回血时，补回的格子连成一片，并且挨着现有的心，像伤口从边上长回来。下一招是回血时，要补的格子会在心阵上用红色虚线提前标出；在它回血之前把伤口旁边的心打碎，这一片就接不上，回血落空。怪物第一次准备回血、虚线框出现时，会弹出一张“打断回血”说明卡，指着虚线框讲怎么做。机制说明只讲一般情况，不提具体的武器、技能或强化。
- 可拾取的道具脚下有四个直角角标：宝箱是木板箱体配金色箍带、锁扣和散落的金币；红心药水是装满红色药液的圆底瓶，头顶飘着一颗旋转的红心；钥匙是悬浮旋转的 IKB 老式钥匙。宝箱和药水特意沿用游戏里通行的样子，方便一眼认出。另有铁栅门（墨黑细栅）与静止的 IKB 方框出口。
- 宝箱、药水和钥匙走上去就拿到，拿完这一格空出来。铁砧要站在旁边点一下使用。没拿的宝箱会一直留在原地，重玩时可以回来拿；只有真正拿到手的武器才算拥有，也才会出现在铁砧的强化里。
- 暗王的红心和招式循环无法事先查看，战斗中只显示它的下一招。小怪的情报可以悬停查看。
- 第 6、8、10、11 章开启战争迷雾：只能看到主角周围约 2.5 格、且没有被障碍挡住视线的格子。走过的区域保留地形，但不显示其中的怪物；未探索的格子被带斜线的灰板盖住。出口始终可见，作为方向地标。自动寻路只经过已探索的格子，也只会绕开看得见的怪物，撞上迷雾里的怪物会直接开战。
- 每章按“抵达出口 / 剩余红心过半 / 回合数达标”评 1–3 星，进度、构筑和看过的说明保存在浏览器 `localStorage`（键名 `heart-gambit-progress-v3`，星级和用过的铁砧按章节的 key 记录，旧存档会自动换算到新的章节顺序）。构筑是跨章节的一份存档（拥有的武器与技能、强化、出战配置、已解锁的武器槽），每通过一章更新一次；回到之前的章节重玩，已解锁的武器槽、武器和技能都不会丢。拿过的宝箱和用过的铁砧在重玩时是打开的，强化不能重复刷。标题页和玩法说明里有「重置进度」，确认后清空解锁、星级、构筑和看过的说明，从序章重新开始，只保留音乐和音效的开关。

| 10 | 王城禁卫 | 迷雾里的精锐车轮战 |
| 11 | 暗王的棋局 | 暗王：王座崩落和王之审判紧挨着，防御只能挡一招 |

**怪物心阵分档成长**：普通怪物的心阵就是它的“符号”——暗影兵是一枚棋子（圆头加底座）、骑士是相邻方块搭成的阶梯、主教是菱形法冠、城堡顶上有城垛（后期两侧是护甲角楼）、王后戴着王冠，左右对称或中心对称。因为连击只认上下左右相邻，心阵的主体也由上下左右相邻的心连成一整片：不能断开、没有孤立的心、只挨着一颗心的细枝不超过三分之一，斜向只做轮廓的边。每一档有 3～4 套变体，共用一个符号模板，只在少数格子上成组增减，遭遇时随机取一套；每一套都通过了形状检查和连击求解器（生成工具见 `tools/gen-matrices.mjs`，标准与单元测试相同）。墨渍怪（序章教学）和暗王（首领）是特殊怪物，只有一套。同一种怪物在前期（序章～第 3 章）、中期（第 4～8 章）、后期（第 9～11 章）心阵不同，越往后涨得越多。每一档心阵都是按武器形状“拼”出来的不规则形：墨渍怪 7 颗，三下拼完并拿到第一点充能；前期暗影兵 12 颗，四个回合内连到第一次追击；前期骑士 12～14 颗，五个回合内一条连击拼完。中后期心阵更厚，靠更多的武器槽、战锤与圣十字、技能和强化来应付，主角的红心矩阵也随章节从 5×5 长到 7×7。

**护甲片**：第 2、5、7、9、10 章的棋盘上各有一块护甲片（黑色漆面方牌，上面四块 2×2 排列的小方甲），走上去就拿到。在棋盘上按 `G` 或点信息栏的护甲片图标，在自己的红心矩阵上选择一块 2×2 区域，其中还在的红心都会披上护甲，被击中时先掉护甲，要两次命中才会消除。


## 音乐与音效

背景音乐和音效全部用 Web Audio 实时合成，不需要下载音频文件。标题、棋盘探索、迷雾章节、普通战斗（墨渍怪、暗影兵）、精锐战斗（骑士、主教、城堡、王后）和暗王战各有一首循环曲，切换时交叉淡入淡出。音效区分轻武器、重武器和技能的挥击，护甲被打裂有金属声，连击的音高随次数升高，获得充能有清亮的提示音，主教祷告、城堡筑墙、定身、铁砧落锤、重抽翻牌等都有各自的声音。顶栏有音乐和音效两个独立开关，设置会记住。

## 手机

手机竖屏单独设计（`src/battle/phone.css`，以 iPhone 17 Pro 的 402×874 为基准），不是把桌面布局等比缩小：页面铺满屏幕并让开灵动岛和底部横条；正文不小于 15px、辅助文字不小于 13px，所有按钮点按区域不小于 44px。顶栏只留章节名、回合数和一个菜单按钮，选择关卡、重新开始、转动视角、玩法说明和声音开关都收进菜单。棋盘上方一条信息栏放红心、药水、钥匙、护甲片以及「武器」「目标」两个按钮，点开后从底部拉出一张居中的窄卡（最宽 380px，内容多时中间滚动）；主角区底部一行是“构筑”按钮，行尾的问号打开“强化说明”弹窗（拥有的武器身上全部强化的“标记 · 名称 / 作用”，说明里的连击、追击用带专属图标的强调色标出）；武器与技能分“出战”“闲置”两段，直接拖动就能换装（手机上长按拿起，也可以点一下拿起、再点目标放下），战斗中锁定；怪物头顶的血量铭牌在竖屏上放大 1.5 倍。章节选择是一行一章的列表。战斗改为上下排布：怪物心阵在上，占满宽度并吃掉剩余高度（出招的地方最大、最好点），心阵的空位和武器够得到的一圈界外格画成虚线格；怪物区底边是一条黑色的“下一招”横条，写明招式和会打掉几颗红心；主角区左右分布：左边是主角心阵，右边是名字、大号红心数和红色 −N（这一招预计的损失），右下角是“当前招式”——选中武器的缩略形状、名字，以及它的旋转、镜像、延长、巨化按钮（没有变形强化时写“方向固定”）；点怪物名字（后面有个小问号）可以查看它的整套招式循环，“目标”抽屉里点怪物那一行也能展开情报；再往下是一行武器卡（列数等于已装备的件数，3～5 列）、一行技能横条（固定三列，右侧小方块是剩余次数）和一整块四格的动作条。冷却中的武器与防御盖上灰色遮罩，中间是沙漏和剩余回合数。电脑上的战斗窗口与武器面板沿用同一套部件样式。矮屏手机会进一步压缩主角区和招式卡，把高度让给怪物心阵。横屏时信息栏竖着贴在左边，面板从左侧拉出；战斗窗口左边是两块心阵，右边一列是招式和动作。

## 操作

- **WASD / 方向键** 移动（随镜头旋转自动适配），**点击格子** 自动寻路，**悬停怪物** 查看情报卡与威胁范围。
- **拖拽** 旋转视角、**滚轮** 缩放、**C** 旋转 90°、**R** 重开本章（需确认）、**P** 棋盘上喝药水、**B** 调整构筑、**H** 玩法说明、**Esc** 章节菜单。
- 战斗中：**数字键** 切换武器与技能、**R / F** 旋转与镜像、**X / G** 延长与巨化（需要强化）、**Q** 防御、**E** 药水、**Z** 等待、**Esc** 取消治疗。触屏上点一次预览、再点同一格确认；小屏有方向键。
