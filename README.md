# 心阵棋局 · Heart Gambit

在线游玩：https://maxwelleako.github.io/YuyuBigAdventure/ 。推送到 `main` 后由 GitHub Actions 自动测试、构建并发布到 GitHub Pages。

一个 Three.js 回合制战棋 Demo。墨水瓶打翻在棋盘上，黑棋一枚接一枚醒了过来，白兵屿屿要走完一个序章和 **11 个章节**，每一章都是一张 8×8 棋盘。

序章只有一条直走廊和一只墨渍怪，用来教红心矩阵和攻击形状。每个新机制第一次出现时都会弹出一张说明卡，看过的不再弹出；在玩法说明里可以关闭新手提示。

## 启动

开发环境使用 Node.js 24，浏览器需要支持 WebGL 2。

```bash
npm install
npm run dev       # 自动打开 http://localhost:5173
npm run build     # 生成 dist，可部署到任意静态网站服务
npm run preview   # 本地预览生产构建
```

## 界面风格

界面采用瑞士国际主义风格（Swiss Style）：灰白纸底 + 单一强调色克莱因蓝 IKB（#002FA7），Inter / Noto Sans SC 无衬线与 JetBrains Mono 元数据，字号越大字重越细，全部直角、纯色、1px 细线，不用阴影、渐变和圆角。约定：**IKB 实底 = 你的攻击或操作，墨黑实底 = 怪物的攻击**，红色只用于红心本身。3D 棋盘是纸白与浅灰两色棋格配墨黑细线，桌面印着与棋格对齐的极细网格。障碍统一是灰色长方体，一眼能认出此路不通。棋子是程序化车削的设计师棋具：主角屿屿是 IKB 釉面小兵，系白色围巾、佩短剑；怪物是黑色漆面的兵、马、象、车、后、王与一滴墨渍，底座与领口有细白线装饰。

## 核心机制：红心矩阵

- 主角和怪物的生命都是一个 **二维红心矩阵**，矩阵被清空即倒下。怪物的矩阵形状各不相同（十字、菱形、带空槽的不规则形），部分怪物有需要命中两次的 **护甲心**。
- 每件武器按 **固定形状** 消除红心，形状 **不能旋转、不能镜像**，也 **不设边界**：越出矩阵的部分直接忽略。例如 L 钩镰（`@#` / `#.`）对准 4×4 矩阵的 a00，会消除 a00、a01、a10；把锚点放到矩阵外，就可以只擦到边缘的一格。
- 战斗窗口左侧是怪物的心阵，右侧是自己的心阵。红心统一使用 7×6 的像素红心。鼠标 **悬停在怪物心阵上预览形状**（小方块是锚点），点击出招。矩阵始终在框内居中，四周铺满与红心格同样大小的虚线“界外格”，形状可以伸到界外。
- 怪物同样用形状攻击，并按固定的 **招式循环** 出招；下一招的形状和 **瞄准位置** 会提前用墨黑色标在你的心阵上。

| 武器 | 形状 | 冷却 | 获得 |
| ---- | ---- | ---- | ---- |
| 短剑 | 横向 2 格 | 无 | 初始 |
| L 钩镰 | L 形 3 格 | 1 | 初始 |
| 斜刃 | 斜向 2 格 | 无 | 第 1 章宝箱 |
| 长枪 | 竖直 3 格 | 1 | 第 2 章宝箱 |
| 战锤 | 3×3，两颗能量豆 | 1 | 第 3 章宝箱 |
| 月镰 | 斜向 3 格 | 1 | 第 4 章宝箱 |
| 破甲锥 | 竖直 2 格，一击击碎护甲心 | 1 | 第 5 章宝箱 |
| 圣十字 | 十字 9 格，两颗能量豆 | 1 | 第 9 章宝箱 |

长枪与月镰以中间一格为锚点，其余武器以左上角为锚点。武器按「小而灵活、大而笨重」分档：短剑、斜刃两格无冷却，是轮换刷连击的主力，但不能延长、不能破甲；钩镰、长枪、月镰、破甲锥负责接招；战锤、圣十字一下打得多，接上连击时立刻追击；怪物蓄力之后的那一记重击，重武器一下打碎 3 颗心就能把它打断。每章宝箱里的武器都是为接下来几章的怪物准备的：长枪对骑士，战锤对骑士的践踏和会回血的主教，破甲锥对城堡。怪物的护甲、回血、蓄力重击、打断连击这些特性，在情报卡和敌人列表里用小图标标出。

**武器槽与构筑**：带进战斗的武器数量受武器槽限制。序章到第 2 章有 2 个槽，第 3～5 章 3 个，第 6～8 章 4 个，第 9 章起 5 个。从第 2 章开始，拥有的武器种类始终多于武器槽，多出的放在背包里。武器槽增加时不会从背包自动补上，新学会的技能也只会放进空着的技能槽，不会替换已带的技能。在棋盘上按 `B` 或点武器标题旁的「打开背包」，左边是出战的武器槽和技能槽，右边是背包，点卡片就能在两侧之间移动；槽位满了时，先点背包里的卡，再点左边要换下的那张。战斗中不能换。

**武器强化**：从第 2 章起每章都有铁砧，镜厅、王后回廊、王城禁卫和终章各有两座，一共 14 座。站在旁边点击它，从三项强化中选一项。每一项可以单独刷新一次，关闭后再打开，选项保持不变；每座铁砧只能用一次。强化有五类：变形（战斗中按 `R` 旋转、按 `F` 镜像，每项强化只提供一种变形，由武器决定：短剑、长枪、破甲锥可旋转，月镰可镜像，L 钩镰两种都能获得，战锤与圣十字变形后形状不变，所以没有变形强化）、延长（中型武器多一格，战锤从 3×3 变成 4×3，圣十字四条臂各再长一格；轻武器不能延长）、精准（这件武器连上时多得一颗能量豆；只给中型和重型武器，出现的概率比其他强化低）、破甲（护甲心一击即碎，破甲锥自带，护甲怪出场之后才会刷出）和震慑（打碎 2 颗心就能打断重击，只给战锤、圣十字）。强化会带到之后的章节。

**连击与能量豆**：攻击形状的每一格都落在还有心的格子上（护甲心也算），就是一次完美命中，它的位置留下蓝色虚线框。换一件武器，挨着虚线框再打一次完美命中，就连成了连击；打空、离虚线框太远或连用同一件武器，连击就断了。连击 ×2 起，每连上一次得一颗能量豆（蓝色菱形），每场战斗开局有两颗，最多攒五颗。短剑、斜刃这些轻武器不花能量豆；钩镰、长枪、月镰、破甲锥每次花一颗，战锤、圣十字每次花两颗，中型、重型武器的冷却都只有 1 回合。于是节奏是：用轻武器连击攒豆，看准时机再换中重型武器出手。重武器一下打碎 3 颗心，还能打断怪物蓄力之后的重击。

**技能**：技能不占武器槽，技能槽固定 3 个，可以在构筑界面更换。每章只能使用有限次数，章节开始时恢复。疾风斩（第 3 章）攻击后可以立刻再用一次普通武器；定身钉（第 5 章）让怪物跳过下一次行动；碎甲（第 6 章）敲碎两格，护甲一击即碎；陨星（第 8 章）攻击 3×3；汲血（第 9 章）消除几颗红心就恢复几颗。

另有 **防御**（不消耗回合，挡下一次伤害，冷却 3）、**红心药水**（消耗回合，在自己心阵上用十字形恢复失去的心；棋盘上也能喝）、**等待**（所有武器都在冷却时跳过这一回合）和 **撤退**（怪物追击一次后晕眩 2 回合，Boss 战不可撤退）。

## 棋盘与怪物

- 与怪物相遇则触发战斗。
- 怪物按棋子规则移动：暗影骑士跳马步追击、暗影主教走斜线并会祷告回血、暗影城堡沿走廊巡逻并给心披甲、暗影王后八方追击，终章的暗王坐镇出口，击败它才能解开封印。
- 怪物回血时，补回的格子连成一片，并且挨着现有的心，像伤口从边上长回来。下一招是回血时，要补的格子会在心阵上用红色虚线提前标出；在它回血之前把伤口旁边的心打碎，这一片就接不上，回血落空。
- 可拾取的道具脚下有四个直角角标：宝箱是木板箱体配金色箍带、锁扣和散落的金币；红心药水是装满红色药液的圆底瓶，头顶飘着一颗旋转的红心；钥匙是悬浮旋转的 IKB 老式钥匙。宝箱和药水特意沿用游戏里通行的样子，方便一眼认出。另有铁栅门（墨黑细栅）与静止的 IKB 方框出口。
- 宝箱、药水和钥匙走上去就拿到，拿完这一格空出来。铁砧要站在旁边点一下使用。没拿的宝箱会一直留在原地，重玩时可以回来拿；只有真正拿到手的武器才算拥有，也才会出现在铁砧的强化里。
- 暗王的红心和招式循环无法事先查看，战斗中只显示它的下一招。小怪的情报可以悬停查看。
- 第 6、8、10、11 章开启战争迷雾：只能看到主角周围约 2.5 格、且没有被障碍挡住视线的格子。走过的区域保留地形，但不显示其中的怪物；未探索的格子被带斜线的灰板盖住。出口始终可见，作为方向地标。自动寻路只经过已探索的格子，也只会绕开看得见的怪物，撞上迷雾里的怪物会直接开战。
- 每章按“抵达出口 / 剩余红心过半 / 回合数达标”评 1–3 星，进度、构筑和看过的说明保存在浏览器 `localStorage`（键名 `heart-gambit-progress-v3`，星级和用过的铁砧按章节的 key 记录，旧存档会自动换算到新的章节顺序）。构筑是跨章节的一份存档（拥有的武器与技能、强化、出战配置、已解锁的武器槽），每通过一章更新一次；回到之前的章节重玩，已解锁的武器槽、武器和技能都不会丢。拿过的宝箱和用过的铁砧在重玩时是打开的，强化不能重复刷。标题页和玩法说明里有「重置进度」，确认后清空解锁、星级、构筑和看过的说明，从序章重新开始，只保留音乐和音效的开关。

## 章节与难度

| 章 | 名称 | 看点 |
| -- | ---- | ---- |
| 序章 | 序章 | 一条走廊、一只墨渍怪。先讲红心矩阵和形状攻击，第一次完美命中、心阵上留下蓝色虚线框之后，再讲连击 |
| 1 | 墨迹初现 | 三道书墙各留一个缺口，墨渍怪和暗影兵堵在缺口上；宝箱里是斜刃 |
| 2 | 兵阵 | 书堆墙只留两个缺口，第一座铁砧 |
| 3 | 骑士巡夜 | 马步追击的骑士、钥匙与铁栅门，学会疾风斩 |
| 4 | 主教长廊 | 会回血的主教 |
| 5 | 墨池 | 一群好打的墨渍怪，适合练连击，学会定身钉 |
| 6 | 城堡之墙 | 迷雾第一次降下，披甲的城堡 |
| 7 | 镜厅 | 主教、城堡、骑士混编，两座铁砧 |
| 8 | 暗夜双骑 | 迷雾中的双骑士，学会陨星 |
| 9 | 王后回廊 | 王后、城堡与骑士，学会汲血 |
| 10 | 王城禁卫 | 迷雾里的精锐车轮战 |
| 11 | 暗王的棋局 | 暗王：王座崩落和王之审判紧挨着，防御只能挡一招 |

难度按「随手玩家」和「思考玩家」两种策略做了模拟：前者每次只挑伤害最大的落点、不防御；后者会接连击、在重击前防御、在合适的时候用技能。中后期随手玩家的失败率在 40%～100%，思考玩家大多在 15% 以内。怪物的心阵按「简单怪能用一条连击链清空，难怪需要选对武器顺序」设计，并用求解器逐个验证过。

## 音乐与音效

背景音乐和音效全部用 Web Audio 实时合成，不需要下载音频文件。标题、棋盘探索、迷雾章节、普通战斗（墨渍怪、暗影兵）、精锐战斗（骑士、主教、城堡、王后）和暗王战各有一首循环曲，切换时交叉淡入淡出。音效区分轻武器、重武器和技能的挥击，护甲被打裂有金属声，连击的音高随次数升高，追击、主教祷告、城堡筑墙、定身、铁砧落锤、重抽翻牌等都有各自的声音。顶栏有音乐和音效两个独立开关，设置会记住。

## 手机

手机上左右两块信息面板收起，只在棋盘上方留一条信息栏：红心、药水、钥匙，以及「武器」「目标」两个按钮，点开后从底部拉出对应的面板，点空白处或右上角收起。棋盘下方有方向键。战斗时怪物和主角的心阵左右并排，招式与动作排在下面，整张战斗卡片一屏放得下。横屏时信息栏竖着贴在左边，面板从左侧拉出；战斗窗口左边是两块心阵，右边一列是招式和动作。

## 操作

- **WASD / 方向键** 移动（随镜头旋转自动适配），**点击格子** 自动寻路，**悬停怪物** 查看情报卡与威胁范围。
- **拖拽** 旋转视角、**滚轮** 缩放、**C** 旋转 90°、**R** 重开本章（需确认）、**P** 棋盘上喝药水、**B** 调整构筑、**H** 玩法说明、**Esc** 章节菜单。
- 战斗中：**数字键** 切换武器与技能、**R / F** 旋转与镜像（需要强化）、**Q** 防御、**E** 药水、**Z** 等待、**Esc** 取消治疗。触屏上点一次预览、再点同一格确认；小屏有方向键。

## 代码组织

浏览器测试使用 Playwright，macOS 上发现系统 Chrome 时直接复用；其他环境先运行 `npx playwright install chromium`。

```text
index.html
public/battle.html    旧地址的跳转页
src/battle/
  main.js             关卡流程、HUD、各类界面与输入
  style.css           瑞士国际主义风格（IKB 单一强调色、Inter/JetBrains Mono、直角 hairline），含手机布局
  audio.js            Web Audio 合成的音效与分场景背景音乐（前瞻调度的步进音序器）
  data/               武器、技能、怪物（矩阵 / 招式循环 / 走法）、序章与八章关卡
  logic/shapes.js     红心矩阵与形状：解析、落点、命中、治疗、排名
  logic/combat.js     回合制战斗状态机（不依赖 DOM）
  logic/board.js      棋盘状态、拾取、迷雾、怪物巡逻 / 追击（BFS）与遭遇
  logic/arsenal.js    武器槽、构筑、强化与铁砧刷新
  render/             Three.js 场景：程序化木纹、旋转体棋子、桌面静物、动画与镜头
  ui/                 红心矩阵组件、战斗窗口、新机制说明弹窗、内联 SVG 图标
```
